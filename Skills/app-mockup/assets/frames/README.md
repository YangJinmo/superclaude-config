# assets/frames

Transparent device frames (iPhone 8, iPhone XS, Galaxy S21 5G) from
[Design at Meta — Devices](https://www.meta.com/design-at-meta/tools/devices/).

The PNGs are NOT committed: the Design@Meta license forbids redistribution and
commercial use without written permission. Download the packs from the link above
and export PNGs named `iphone-8-silver.png`, `iphone-xs-space-grey.png`,
`galaxy-s21-black.png`, etc. into this folder (see SKILL.md, "번들 프레임 에셋").
